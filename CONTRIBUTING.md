# Contributing to open-MFE

Thank you for helping build the open-MFE!

## How to Contribute

1. Fork this repository
2. Navigate to the relevant module folder (e.g., `01_mathematical_foundations/stochastic_calculus_I/`)
3. Add your resource to `RESOURCES.md` using the template below
4. Open a pull request with a brief description of what you're adding

## Resource Template

```markdown
### [Resource Name](URL)
- **Type:** Textbook | Course | Paper | Repo | Lecture
- **Author/Institution:** ...
- **Level:** Introductory | Intermediate | Advanced
- **Free:** Yes | Partial | No
- **Covers:** [list of specific topics from the module]
- **Notes:** Why this resource is particularly good
```

## Quality Standards

- Resources must be **openly available** (free, legally accessible).
- In case of books if there are non-free books that are still worth mentioning, we can add them as recommended.
- (optional) Annotate *why* the resource is good, not just what it covers
- Sometimes it's hard to match the exact topic of a module to a course/book. In this case, we can add the resource to the most relevant module or link to it from multiple modules if it makes sense.

## Contribution Ideas

- 📖 Add textbook chapters (with legal free PDF links)
- 🎓 Add MOOC links (MIT OCW, Coursera audit, edX, YouTube playlists)
- 📄 Add seminal papers (arXiv, SSRN links)
- 💻 Add GitHub repos, Jupyter notebooks, QuantLib examples
- 🗂️ Add lecture notes from professors who make them public
- 💡 Add a new capstone project idea to `11_capstone_projects/project_ideas/`
