##  Textbooks

### *C++ Design Patterns and Derivatives Pricing* — Mark Joshi
- **Type:** Textbook
- **Author/Institution:** Mark Joshi (University of Melbourne)
- **Level:** Intermediate
- **Free:** No (Cambridge University Press)
- **Covers:** Monte Carlo pricing engines, design patterns, abstract classes, templates, STL for finance, call and put pricing
- **Notes:** The canonical C++ text for quantitative finance. Teaches C++ through derivatives pricing implementations. Widely used in Baruch MTH 9821 and CMU 46902. Essential for quant developer roles.

### *C++ Primer* — Stanley Lippman, Josée Lajoie & Barbara Moo
- **Type:** Textbook
- **Author/Institution:** Lippman, Lajoie & Moo
- **Level:** Introductory
- **Free:** No (Addison-Wesley)
- **Covers:** C++ fundamentals, STL containers, classes, templates, lambda expressions, memory management
- **Notes:** The comprehensive C++ language reference before specializing in finance. Read alongside Joshi for full language coverage and application.

### *Quantitative Finance in C++* — Michael Quantlib Community
- **Type:** Textbook
- **Author/Institution:** Various (QuantLib community)
- **Level:** Advanced
- **Free:** Partial (QuantLib documentation freely available at [quantlib.org](https://www.quantlib.org/))
- **Covers:** QuantLib library architecture, fixed income pricing, Monte Carlo, finite differences in C++
- **Notes:** QuantLib is the industry-standard open-source C++ library for quantitative finance. The documentation and examples serve as the de facto advanced C++ finance text.
