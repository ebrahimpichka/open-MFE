## 📖 Textbooks

### [Learning SQL — Alan Beaulieu](https://www.oreilly.com/library/view/learning-sql-3rd/9781492057604/)
- **Type:** Textbook
- **Author/Institution:** Alan Beaulieu (O'Reilly)
- **Level:** Introductory
- **Free:** No (O'Reilly; older edition widely available)
- **Covers:** SELECT, joins, subqueries, aggregation, set operations, stored procedures, transactions
- **Notes:** The most widely recommended SQL book for beginners. Clear progression from fundamentals to advanced queries. Ideal for MFE students needing database skills for financial data.

### *Database System Concepts* — Abraham Silberschatz, Henry Korth & S. Sudarshan
- **Type:** Textbook
- **Author/Institution:** Silberschatz, Korth & Sudarshan (Wiley)
- **Level:** Intermediate
- **Free:** No (McGraw-Hill)
- **Covers:** Relational model, SQL, relational algebra, normalization, transaction management, indexing, query optimization
- **Notes:** The standard computer science database textbook. Essential for understanding the internals of database systems used in financial data infrastructure.
