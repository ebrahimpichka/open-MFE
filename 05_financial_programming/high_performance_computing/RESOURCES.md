# 5.4 — High-Performance Computing

`UChicago: FINM 32950, FINM 32700`

## 🎓 Courses & Lectures

### Parallel Computing

- **[Stanford CS149 — Parallel Computing (2023)](https://www.youtube.com/playlist?list=PLoROMvodv4rMp7MTFr4hQsDEcX7Bx6Odp)**
  Comprehensive coverage of parallel hardware and software. SIMD, multithreading, GPU architecture, distributed memory.

- **[Intro to Parallel Programming — Udacity / UC Davis](https://www.youtube.com/playlist?list=PLAwxTw4SYaPnFKojVQrmyOGFCqHTxfdv2)**
  Hands-on introduction to parallel programming concepts. [Alternate link](https://www.youtube.com/playlist?list=PLnH7E0IG44jFfiQBd_Ov7FmYHq8SZx6r0)

- **[2024 High Performance Computing Course](https://www.youtube.com/playlist?list=PLmJwSK7qduwVAnNfpueCgQqfchcSIEMg9)**
  Modern HPC techniques including MPI, OpenMP, and performance profiling.

- **[ARCHER2 Online Training](https://www.archer2.ac.uk/training/online/)**
  Free HPC training materials from the UK national supercomputing service. Covers MPI, OpenMP, performance tools.

### CUDA & GPU Computing

- **[CUDA Crash Course](https://www.youtube.com/playlist?list=PLxNPSjHT5qvtYRVdNN1yDcdSl39uHV_sU)**
  Fast-paced introduction to CUDA programming. Ideal for implementing GPU-accelerated Monte Carlo.

- **[Programming Massively Parallel Processors — Lecture Series](https://www.youtube.com/@pmpp-book)**
  Based on the canonical CUDA textbook by Hwu, Kirk & Hajj. Covers GPU memory hierarchy, thread organization, optimization.

- **[GPU MODE](https://www.youtube.com/@cudamode)** · [GitHub](https://github.com/gpu-mode)
  Community-driven GPU programming resources. Covers Triton, CUDA kernels, performance engineering.

- **[Parallel Computing Using CUDA-C](https://github.com/CisMine/Parallel-Computing-Cuda-C)**
  Practical code-focused repository for CUDA programming patterns.

- **[CUDA Training Series — ORNL / NERSC](https://www.youtube.com/playlist?list=PL6RdenZrxrw-zNX7uuGppWETdxt_JxdMj)**
  [Exercises on GitHub](https://github.com/olcf/cuda-training-series/tree/master/exercises)
  Professional HPC center training. Covers advanced CUDA patterns, profiling, multi-GPU.
