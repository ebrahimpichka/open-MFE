##  Textbooks

### [Speech and Language Processing (3rd ed. draft) — Daniel Jurafsky & James H. Martin](https://web.stanford.edu/~jurafsky/slp3/)
- **Type:** Textbook
- **Author/Institution:** Daniel Jurafsky & James H. Martin (Stanford University)
- **Level:** Intermediate
- **Free:** Yes
- **Covers:** Language models, sequence labeling, parsing, sentiment analysis, information extraction, machine translation, Transformers, LLMs
- **Notes:** The canonical NLP textbook, freely available as a draft at web.stanford.edu/~jurafsky/slp3. Frequently updated with latest advances including Transformer-based models and LLMs. Essential reference for NLP in finance.

### [Natural Language Processing with Python (NLTK Book) — Bird, Klein & Loper](https://www.nltk.org/book/)
- **Type:** Textbook
- **Author/Institution:** Steven Bird, Ewan Klein & Edward Loper
- **Level:** Introductory
- **Free:** Yes
- **Covers:** Tokenization, POS tagging, parsing, classification, information extraction, text corpora
- **Notes:** Freely available online. Hands-on Python introduction to NLP tasks. Good foundation before moving to Transformer-based approaches for financial text analysis.

### [Introduction to Information Retrieval — Manning, Raghavan & Schütze](https://nlp.stanford.edu/IR-book/)
- **Type:** Textbook
- **Author/Institution:** Christopher Manning, Prabhakar Raghavan & Hinrich Schütze (Stanford)
- **Level:** Intermediate
- **Free:** Yes
- **Covers:** Boolean retrieval, TF-IDF, vector space models, probabilistic retrieval, query expansion, text classification
- **Notes:** Freely available online from Stanford NLP group. Foundation for document retrieval and search systems applied to financial text (earnings reports, news, filings).
