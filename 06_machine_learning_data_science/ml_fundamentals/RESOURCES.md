# 6.1 — Machine Learning Fundamentals

## 🎓 Courses & Lectures

- **[Stanford CS229 — Machine Learning (Spring 2022)](https://www.youtube.com/playlist?list=PLoROMvodv4rNyWOpJg_Yh4NSqI4Z4vOYy)**
  The canonical ML course. Supervised/unsupervised learning, SVMs, neural networks, EM, PCA, reinforcement learning.

- **[Stanford Statistical Learning with Python](https://www.youtube.com/playlist?list=PLoROMvodv4rPP6braWoRt5UCXYZ71GZIQ)**
  Based on *An Introduction to Statistical Learning* ([free textbook](https://www.statlearning.com/)). Regression, classification, resampling, shrinkage, tree methods, SVMs.

- **[Introduction to Machine Learning — Sebastian Raschka](https://www.youtube.com/playlist?list=PLTKMiZHVd_2KyGirGEvKlniaWeLOHhUF3)**
  Practical and rigorous. Covers the full ML pipeline with Python. Strong on model evaluation and regularization.

- **[Georgia Tech CS 7641 — Machine Learning](https://edstem.org/us/join/D3Um7q)**
  Graduate-level ML with strong theoretical foundations. Covers supervised, unsupervised, and reinforcement learning.
