# 6.2 — ML for Finance

`CMU: 46926, 46927 | UChicago: FINM 33160`

Applications of machine learning specifically to financial markets: alpha generation, portfolio construction, and systematic trading.

##  Courses & Lectures

- **[Georgia Tech CS 7646 — Machine Learning for Trading](https://edstem.org/us/join/HsVgWm)**
  Finance-specific ML applications: technical indicators as features, Q-learning for trading, portfolio optimization with ML. Directly maps to MFE curriculum.

- **[Advances in Financial Machine Learning — Hudson & Thames Research](https://www.youtube.com/playlist?list=PLfv9eTYgatm0n1TuVZSkWs0OoCsYlRIto)**
  Lecture series based on Marcos López de Prado's *Advances in Financial Machine Learning*. Covers financial data structures, feature engineering, backtesting pitfalls, and meta-labeling.

##  Textbooks

### *Advances in Financial Machine Learning* — Marcos López de Prado
- **Type:** Textbook
- **Author/Institution:** Marcos López de Prado (Cornell University / AQR)
- **Level:** Advanced
- **Free:** No (Wiley)
- **Covers:** Financial data structures, labeling, feature engineering, ensemble methods, backtesting, meta-labeling, bet sizing
- **Notes:** The definitive ML reference for quantitative finance. Fundamentally changes how ML is applied to financial data. Required reading for systematic trading research. Lecture series freely available on YouTube.

### *Machine Learning for Algorithmic Trading* — Stefan Jansen
- **Type:** Textbook
- **Author/Institution:** Stefan Jansen (Packt)
- **Level:** Intermediate
- **Free:** No (Packt)
- **Covers:** Financial feature engineering, ML models (tree methods, neural networks), NLP for finance, reinforcement learning for trading, backtesting
- **Notes:** Comprehensive practical guide with full Python implementations. Covers the entire ML pipeline for systematic trading. Strong complement to López de Prado's more theoretical work.

### *Machine Learning for Asset Managers* — Marcos López de Prado
- **Type:** Textbook
- **Author/Institution:** Marcos López de Prado (Cambridge University Press)
- **Level:** Advanced
- **Free:** No
- **Covers:** Unsupervised learning for finance, clustering, principal portfolios, structural breaks, statistical arbitrage
- **Notes:** Focused specifically on asset management ML applications. More theoretical than AFML. Part of the Cambridge Elements series on quantitative finance.
