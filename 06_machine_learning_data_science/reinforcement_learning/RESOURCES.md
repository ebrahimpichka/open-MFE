# 6.5 — Reinforcement Learning

`UChicago: FINM 33165`

## 🎓 Courses & Lectures

- **[UC Berkeley CS 285 — Deep Reinforcement Learning (Fall 2023)](https://www.youtube.com/playlist?list=PL_iWQOsE6TfVYGEGiAOMaOzzv41Jfm_Ps)**
  [Course page](http://rail.eecs.berkeley.edu/deeprlcourse/). The leading academic DRL course. Policy gradients, actor-critic, model-based RL, offline RL.

- **[UCL Course on RL — David Silver (2015)](https://www.davidsilver.uk/teaching/)**
  [YouTube playlist](https://www.youtube.com/watch?v=2pWv7GOvuf0). The foundational RL course. MDPs, dynamic programming, TD learning, Q-learning, policy gradient.

- **[Stanford CS234 — Reinforcement Learning (Spring 2024)](https://www.youtube.com/playlist?list=PLoROMvodv4rN4wG6Nk6sNpTEbuOSosZdX)**
  [Winter 2019 version](https://www.youtube.com/playlist?list=PLoROMvodv4rOSOPzutgyCTapiGlY2Nd8u)
  Covers value-based, policy-based, and model-based RL with a strong application focus.

- **[Stanford CS224R — Deep Reinforcement Learning](https://www.youtube.com/playlist?list=PLoROMvodv4rPwxE0ONYRa_itZFdaKCylL)**
  Advanced DRL: offline RL, inverse RL, multi-task RL, representation learning for RL.

- **[UWaterloo CS885 — Reinforcement Learning (Spring 2020) — Pascal Poupart](https://www.youtube.com/playlist?list=PLdAoL1zKcqTUcyfWgzKuTMf-mbiopsKLh)**
  [Course page](https://cs.uwaterloo.ca/~ppoupart/teaching/cs885-spring20/)
  Rigorous treatment with strong Bayesian RL coverage. More recent versions on Dr. Poupart's website.

- **[Theoretical Foundations of Reinforcement Learning — Csaba Szepesvári (UAlberta)](https://www.youtube.com/@rltheory1586)**
  [Course page](https://rltheory.github.io/). Mathematical RL theory: PAC bounds, regret analysis, sample complexity.

- **[Introduction to Reinforcement Learning — Masoud Farahmand](https://www.youtube.com/playlist?list=PLCveiXxL2xNbiDq51a8iJwPRq2aO0ykrq)**
  Accessible entry point covering the full RL pipeline from MDPs through modern deep RL.
