## 🎓 Courses & Lectures

- **[Matrix Algebra — Prof. Wen Shen (UPenn)](https://www.youtube.com/playlist?list=PLbxFfU5GKZz0f6Gc885DGb8ZeTKyef76p)**
  Focused, applied treatment. Matrix operations, eigenvalues, systems of equations. Great for finance applications.

- **[Linear Algebra — Princeton University](https://www.youtube.com/playlist?list=PLGqzsq0erqU7w7ZrTZ-pWWk4-AOkiGEGp)**
  Well-structured undergraduate course. Covers vector spaces, linear maps, determinants, eigendecomposition.

- **[Linear Algebra Done Right — Sheldon Axler (lecture series)](https://www.youtube.com/playlist?list=PLGAnmvB9m7zOBVCZBUUmSinFV0wEir2Vw)**
  Based on the canonical graduate-level text. Proof-based, abstract approach. Essential for rigorous understanding of PCA and SDF theory.

## 📖 Textbooks

### [Introduction to Linear Algebra — Gilbert Strang (MIT)](https://math.mit.edu/~gs/linearalgebra/)
- **Type:** Textbook
- **Author/Institution:** Gilbert Strang (MIT)
- **Level:** Introductory
- **Free:** Partial (lecture videos free on MIT OCW; textbook for purchase)
- **Covers:** Matrix operations, vector spaces, eigenvalues/eigenvectors, SVD, positive definite matrices
- **Notes:** The canonical undergraduate linear algebra text, paired with the famous [MIT 18.06 lecture series](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/). The OCW course materials are fully free.

### *A Linear Algebra Primer for Financial Engineering* — Dan Stefanica
- **Type:** Textbook
- **Author/Institution:** Dan Stefanica (Baruch College)
- **Level:** Intermediate
- **Free:** No
- **Covers:** Covariance matrices, PCA, least squares, Cholesky decomposition, LU factorization, eigendecomposition
- **Notes:** Specifically written for MFE applicants. Bridges abstract linear algebra and quantitative finance applications. Widely used in Baruch's pre-MFE program.

### *Linear Algebra Done Right* — Sheldon Axler
- **Type:** Textbook
- **Author/Institution:** Sheldon Axler (San Francisco State University)
- **Level:** Intermediate
- **Free:** Partial (4th edition freely available at [linear.axler.net](https://linear.axler.net/))
- **Covers:** Vector spaces, linear maps, inner product spaces, spectral theorem (without determinants)
- **Notes:** Proof-based approach emphasizing linear maps over matrix manipulation. Essential for rigorous understanding of PCA and stochastic discount factor theory. 4th edition is legally free online.
