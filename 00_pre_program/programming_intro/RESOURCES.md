## 📖 Textbooks

### [Natural Language Processing with Python (NLTK Book) — Bird, Klein & Loper](https://www.nltk.org/book/)
- **Type:** Textbook
- **Author/Institution:** Steven Bird, Ewan Klein, Edward Loper (O'Reilly / NLTK Project)
- **Level:** Introductory
- **Free:** Yes
- **Covers:** Python programming fundamentals, text processing, data structures, file I/O
- **Notes:** Freely available online. Uses NLP examples to teach core Python — excellent for MFE students with no prior programming background.

### *Fluent Python* — Luciano Ramalho
- **Type:** Textbook
- **Author/Institution:** Luciano Ramalho (O'Reilly)
- **Level:** Intermediate
- **Free:** No
- **Covers:** Pythonic idioms, data structures, functions, classes, concurrency, metaprogramming
- **Notes:** The definitive intermediate Python reference. Bridges beginner Python to the idiomatic, high-performance code used in quantitative finance libraries.

### *C++ Primer* — Stanley Lippman, Josée Lajoie & Barbara Moo
- **Type:** Textbook
- **Author/Institution:** Lippman, Lajoie & Moo
- **Level:** Introductory
- **Free:** No
- **Covers:** C++ fundamentals, STL, classes, templates, memory management
- **Notes:** The standard introductory C++ text before specializing in quantitative finance applications. Foundation for Module 5.2 (C++ for Finance).
